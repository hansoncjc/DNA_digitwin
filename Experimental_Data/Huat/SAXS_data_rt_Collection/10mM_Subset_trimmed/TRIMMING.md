# Huat 10 mM subset — trimmed S(q) curves

Trimmed **S(q)** arrays for the six 10 mM NaCl Huat conditions used in black-box / NN optimization.

## Folder layout

```
SAXS_data_rt_Collection/
├── 10mM_Subset/
│   ├── I(q)/          original experimental I(q) .npy (unchanged)
│   └── S(q)/          S(q) generated by trim_subset_by_q.py (I→S via repo form factor)
└── 10mM_Subset_trimmed/
    ├── *_trimmed.npy  trimmed S(q) at user-specified q cutoffs
    ├── trim_plots/    preview figures
    └── trim_subset_by_q.py
```

| `chol_140_nacl_10_bridge_20.npy` | 20 | 140 | 10 |

Each trimmed file is `[q, S(q)]` with shape `(N, 2)`.

## I(q) → S(q)

Uses `DNA_digitwin/scattering.extract_exp_sq` with form factor
`formfactors/sasmodels_sphere_fit.txt` (polydisperse sphere), normalization q-window `[0.003, 0.06]` Å⁻¹.

## Trimming logic

**Keep S(q) from the beginning of the curve up to (and including) the first minimum after the first peak.**

Set per-file cutoffs in `trim_subset_by_q.py` → `TRIM_Q` (q in Å⁻¹). Rows with `q <= q_trim` are kept.

When updating training scripts, point `EXP_ROOT` at this folder and use `datatype="sq"`.
